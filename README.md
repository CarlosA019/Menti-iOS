# Menti-iOS App
Menti: Menti is a medication tracker designed to support mental health wellness. It provides daily motivational quotes and offers resources for common mental health disorders.

Features:

Medication Tracker: Easily track your medications and doses.
Daily Motivational Quotes: Receive uplifting quotes daily to boost your mood.
Resource Library: Access valuable resources for managing various mental health disorders.

--------------------------
Installation Requirements
iOS 17.0+
Xcode 14.0+
